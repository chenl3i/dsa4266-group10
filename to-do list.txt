[ ] NVD API RETRY POLICY
    File: src/vulnprio/data/sources/nvd.py, build_transport()
    Still a stub. It is NOT needed for the one-time pull, which is complete.
    It is needed only if we later add incremental (delta) pulls.
    The docstring lists the four trade-offs.

[ ] NVD REVISION LEAK - WRITE AN ADR
    The NVD gives each CVE its CURRENT state, not its state in the past. A
    2021 training row carries 2026 analyst knowledge. This is a real leak.
    Two honest options:
      (a) accept it and state it as a limitation in the report, or
      (b) use only fields that analysts do not revise.
    Most published work does (a). Write the decision down either way.

[ ] BASE RATE IS LOW
    About 1,538 positives in about 180,000 rows. That is 0.85 percent.
    At k = 0.5 percent we rank about 900 CVEs. The confidence intervals will
    be wide. Do not read a single point estimate as a result.

[ ] --year FLAG IS MIN/MAX, NOT A SET
    File: src/vulnprio/cli.py
    "--year 2015 --year 2020" fetches 2015 THROUGH 2020, not those two years.
    Fine for a smoke test. Rename it or change it if this confuses anyone.
