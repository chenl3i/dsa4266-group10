## Review Focus

1. Calib too short for `rate` to pick any row, or every scored position injected → AUC undefined; return `nan`, do not raise. Test in Task 2.
2. Scorers that return fewer positions than rows (windowed models drop each segment's first `length - 1` minutes) → the AUC must use `mask[positions]`, not the full mask. Test in Task 2.
3. Same injected rows for every model and seed, so sanity AUCs are comparable across the comparison table → fixed injection seed, not the run seed. Test in Task 2.
4. The sanity check must not mutate the calib array the run later scores for the threshold. Test in Task 2 (helper) and Task 3 (threshold still equals the clean-calib quantile, existing test).
5. A future change to `TUNE_FRACTION` or `FIT_ROWS` silently moving the split → real-data test pins 9,826 / 9,827 rows and the gap dates. Test in Task 4.

### Task 2: Shared synthetic sanity check

**Files:**
- Modify: `src/ugr16ad/synthetic.py`
- Test: `tests/test_synthetic.py`

**Interfaces:**
- Consumes: `inject_anomalies(X, *, rate, magnitude, n_features, seed) -> (X_copy, mask)` (existing).
- Produces, in `ugr16ad.synthetic`:
  - `SANITY_RATE = 0.01`
  - `SANITY_GRID = ((2.0, 1), (2.0, 5), (4.0, 1), (4.0, 5))`, each `(magnitude, n_features)`
  - `SANITY_SEED = 0`
  - `sanity_check(X: np.ndarray, score_rows: Callable[[np.ndarray], tuple[np.ndarray, np.ndarray]], *, rate: float = SANITY_RATE, seed: int = SANITY_SEED) -> list[dict[str, float]]`
    - `X` is preprocessed calib, `(rows, features)`.
    - `score_rows(X_injected)` returns `(scores, positions)`: one score per scored row and the row index each score belongs to (`np.arange(len(X))` for single-minute models; the `positions` from `make_windows` for windowed ones).
    - Returns one dict per grid entry, in grid order: `{"magnitude", "n_features", "auc"}`; `auc = roc_auc_score(mask[positions], scores)`, or `nan` when `mask[positions]` holds one class.

- [ ] **Step 1: Write the failing tests** in `tests/test_synthetic.py`. Use `X = np.random.default_rng(1).normal(size=(2000, 8))` and an oracle scorer `def max_abs(X): return np.abs(X).max(axis=1), np.arange(len(X))`.

```python
def test_sanity_check_follows_the_grid():
    result = sanity_check(X, max_abs)
    assert [(r["magnitude"], r["n_features"]) for r in result] == list(SANITY_GRID)

def test_sanity_check_bigger_anomalies_score_higher():
    by_key = {(r["magnitude"], r["n_features"]): r["auc"] for r in sanity_check(X, max_abs)}
    assert by_key[(4.0, 5)] > 0.95
    assert by_key[(4.0, 5)] > by_key[(2.0, 1)]

def test_sanity_check_uses_only_scored_positions():
    # Drop the first 19 rows, as a 20-minute window scorer would.
    def windowed(X):
        pos = np.arange(19, len(X))
        return np.abs(X[pos]).max(axis=1), pos
    assert all(np.isfinite(r["auc"]) for r in sanity_check(X, windowed))

def test_sanity_check_single_class_is_nan():
    assert all(np.isnan(r["auc"]) for r in sanity_check(X[:10], max_abs))  # round(0.1) = 0 rows

def test_sanity_check_is_reproducible_and_leaves_X_alone():
    before = X.copy()
    assert sanity_check(X, max_abs) == sanity_check(X, max_abs)
    np.testing.assert_array_equal(X, before)
```
