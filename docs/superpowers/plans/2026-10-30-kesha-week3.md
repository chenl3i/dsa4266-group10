already on `working`: move it to the agreed path, give it a run script that writes the
standard results format, fix its capacity on tune loss, check preprocessing and window
boundaries on the real data, then produce 3-seed CNN results for the comparison table.

**Architecture:** The model stays a plain `nn.Module` in `src/ugr16ad/models/cnn.py`.
Everything else is the shared pipeline: `Preprocessor`, `make_windows`, `train_autoencoder`,
`score_autoencoder`, `fit_threshold`, the metrics in `evaluate.py`, `synthetic.sanity_check`
and `results.save_run`. `scripts/run_cnn.py` only wires them together, so a difference in
the comparison table comes from the model, not the plumbing. The pipeline checks are slow
real-data tests next to the existing unit tests.

**Tech Stack:** Python 3.11, NumPy, pandas, scikit-learn, PyTorch, pytest, ruff.

**Spec:** `docs/team-plan.md` (Kesha's week 3 part), `docs/DSA4266.md`, `CLAUDE.md`
(rules the proposal fixes).

## Global Constraints

- Settled on 26 Oct: window length `20`, `TUNE_FRACTION = 0.5`, synthetic sanity check
  `synthetic.SANITY_GRID` on preprocessed calib.
- Threshold = 99th percentile of calib scores, frozen (`evaluate.fit_threshold`). Never
  refit on test.
- Never tune any setting on test scores or labels. The capacity sweep reads tune loss only.
- Shared training defaults, as in the LSTM run: Adam, `lr=1e-3`, `batch_size=256`,
  `epochs=50`, `patience=5`, seeds `0 1 2`, CPU.
- The model folder is `reports/results/cnn/seed<seed>/` and `meta["model"] == "cnn"`.
- Docstrings explain why, not what. Unit tests use tiny synthetic fixtures; only
  `@pytest.mark.slow` tests read the real CSVs.
- Python: `./.venv/Scripts/python.exe` (Windows) or `./.venv/bin/python` (macOS/Linux).
  Ruff: `ruff check` and `ruff format --check` clean on `src tests` (what CI runs) and on
  `scripts/run_cnn.py`. `scripts/eda_checks.py` already fails ruff and is not Kesha's to fix.
- Branch `kesha/week3` off `origin/working`; PR into `working`. Results to Vanessa by
  Sun 1 Nov; results lock Tue 3 Nov.

   `n_parameters`, `train_seconds` and `inference_seconds`. A misspelt key gives a blank
   cell, not an error. Test in Task 2.
2. `make_comparison_table.common_minutes` stops if models scored different test minutes.
   The CNN must score exactly `eligible_positions(segment, 20)` of each part. Test in Task 2.
3. Stride-2 convolution on an odd window length: `ConvTranspose1d(..., output_size=...)`
   must give back the input length. Existing test with length 19 in `tests/test_cnn.py`
   must keep passing after the move.
4. `inference_seconds` must time calib + test scoring, the same span the windowed MLP
   times, so the speed column is comparable.
5. The sanity check must not mutate the calib array that sets the threshold. Covered by
   `sanity_check` itself; Task 2 checks the threshold still equals the clean-calib quantile.

```python
def test_writes_a_loadable_cnn_run(run_path):
    assert load_run(run_path).meta["model"] == "cnn"

def test_meta_has_the_comparison_table_keys(run_path):
    meta = load_run(run_path).meta
    for key in ("threshold", "n_parameters", "train_seconds", "inference_seconds"):
        assert meta[key] is not None

def test_scores_the_shared_eligible_positions(parts, run_path):
    scores = load_run(run_path).scores
    for name, part in parts.items():
        expected = part.X.index[eligible_positions(part.segment.to_numpy(), WINDOW)]
        got = scores.loc[scores["part"] == name, "timestamp"]
        assert list(got) == list(expected)

def test_threshold_is_the_calib_quantile(run_path):
    run = load_run(run_path)
    calib = run.scores.loc[run.scores["part"] == "calib", "score"].to_numpy()
    assert run.meta["threshold"] == pytest.approx(fit_threshold(calib))

def test_meta_records_sanity_check(run_path):
    checks = load_run(run_path).meta["sanity_check"]
    assert [(c["magnitude"], c["n_features"]) for c in checks] == [list(g) for g in SANITY_GRID]
```
